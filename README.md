## 🚀 Избранные публичные проекты

### 🛡️ Информационная безопасность & Системное ПО
- **[NormativesDB](https://github.com/Leonid-Perkin/NormativesDB)**  
  База данных на C++ для хранения и анализа результатов спортивных нормативов. Поддерживает бинарное хранение, быстрый поиск/сортировку и шифрование данных средствами OpenSSL.  
  `C++` `OpenSSL` `Криптография` `Бинарные структуры`
- **[School_Guard](https://github.com/Leonid-Perkin/School_Guard)**  
  Система мониторинга и контроля доступа (СКУД) для образовательных учреждений, построенная на базе современных стандартов безопасности.  
  `C++` `Python` `Безопасность` `СКУД`
- **[Smart_Garage](https://github.com/Leonid-Perkin/Smart_Garage)**  
  Умный гараж на C++: автоматизация элементов хранения, разграничение доступа и интеграция с внешними исполнительными устройствами.  
  `C++` `IoT` `Контроль доступа`

### 🎧 Системные расширения & Desktop
- **[OwlPods](https://github.com/Leonid-Perkin/OwlPods)**  
  Продвинутый компаньон для Apple AirPods в среде GNOME Shell (Linux / Wayland / BlueZ D-Bus). Парсинг недокументированных BLE Proximity-маячков производителя, всплывающие плавные карточки в стиле iOS/macOS, индикация заряда кейса и наушников, а также автопауза по датчику уха через MPRIS.  
  `JavaScript (GJS)` `GNOME Shell` `BlueZ D-Bus` `BLE Proximity Beacons` `Linux`
- **[History_game](https://github.com/Leonid-Perkin/History_game)**  
  Образовательная интерактивная игра, посвящённая истории Великой Отечественной войны.  
  `C#` `WPF` `XAML`

### ⚡ Автоматизация, REST API & Боты
- **[schedule-api-RTU-Mirea](https://github.com/Leonid-Perkin/schedule-api-RTU-Mirea)**  
  Высокопроизводительный асинхронный REST API сервис расписания РТУ МИРЭА на базе FastAPI. Включает скрапинг динамических страниц через Playwright (Chromium), кэширование и Docker-окружение.  
  `FastAPI` `Playwright` `Docker` `Pydantic` `Swagger`
- **[OwlBot](https://github.com/Leonid-Perkin/OwlBot)**  
  Многофункциональный Telegram-бот: расписание, гороскопы, массовые упоминания. Сконфигурирован для развёртывания в Docker с поддержкой платформ `amd64` и `arm64`.  
  `Python` `Docker (Multi-arch)` `Telegram Bot API`

### 🌐 Web & Исследования
